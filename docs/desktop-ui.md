# Desktop UI 크기 맞춤

설치 AI는 기존 ChatGPT·Claude 데스크톱 앱을 확인하고, 사용자가 익숙한 크기에 Hermes Desktop을 맞춘다. 창 크기뿐 아니라 메뉴·버튼·입력창의 UI 배율과 채팅 글자 크기를 비교한다. 기존 앱의 디자인이나 설정 파일을 복사하지 않는다.

## 기준 앱 선택

| 기존 환경 | 처리 |
|---|---|
| ChatGPT 또는 Claude 한 앱만 사용 | 그 앱을 기준으로 적용 |
| 두 앱을 사용하며 크기가 같음 | 확인 가능한 앱 하나를 기준으로 적용 |
| 두 앱의 크기가 다름 | 사용자가 지정한 주 사용 앱을 기준으로 적용; 지정이 없으면 한 번 확인 |
| 두 앱 모두 없음 | 현재 Hermes UI 설정 유지; 새 설치는 기본값 사용 |
| 앱은 있지만 크기를 확인할 수 없음 | 임의 값을 적용하지 않고 원인과 미확인 항목 기록; 필요한 OS 권한이나 기준 화면만 요청 |

앱 이름은 데스크톱 ChatGPT·Claude를 뜻한다. Codex·Claude Code의 터미널 글자 크기나 계정 제공자 설정을 기준으로 삼지 않는다.

## 적용

1. 기존 Hermes 창 크기·UI 배율·채팅 글자 설정을 확인해 되돌릴 수 있도록 로컬에 기록한다. 이미 기준에 맞으면 변경하지 않는다.
2. 접근성 정보나 허용된 화면 비교로 기준 앱의 창 크기와 글자·컨트롤의 표시 크기를 확인한다. 같은 디스플레이 조건에서 비교하며, Retina 화면의 물리 픽셀과 macOS 창 좌표를 혼동하지 않는다. 앱 설치 여부만으로 현재 크기를 추정하지 않는다.
3. Hermes 창 크기를 기준 앱에 맞추되 현재 디스플레이의 작업 영역을 넘기지 않는다. 전체화면·최대화 상태는 일반 창 크기와 구분하고 임의로 해제하지 않는다.
4. 설치된 버전의 Settings → Appearance에서 UI Scale과 채팅 글자 배율을 조정한다. 전체 UI를 먼저 맞춘 뒤 본문만 차이가 있으면 채팅 글자 배율을 조정한다. 두 앱의 배율 숫자가 같아도 실제 표시 크기는 다를 수 있으므로 화면에서 비교한다. 설정 이름·지원 범위는 설치 버전에서 다시 확인한다.
5. Hermes의 지원 설정과 창 제어 기능으로 적용한다. 다른 프로필·테마·폰트·레이아웃은 보존한다. UI 크기를 맞추려고 앱 소스·CSS를 패치하거나 확인하지 않은 설정 키를 만들지 않는다.

작업 내내 원래 앱의 포커스·키보드 입력 대상·커서를 보존한다. 기존 ChatGPT·Claude 앱을 이동·크기 변경·종료하지 않는다. 참고 앱을 새로 열거나 전면으로 가져와야 하면 먼저 확인하며, 백그라운드 제어가 실패해도 몰래 전면 조작으로 전환하지 않는다. 실행 중인 Hermes를 강제 종료하거나 작업 중인 세션을 초기화하지 않는다.

## 완료 확인

- 기준 앱과 Hermes의 창 크기·UI 요소·채팅 본문을 실제로 비교한다.
- 입력창과 메뉴가 잘리지 않고 대화 스크롤·입력이 되는지 확인한다. 테마·기존 레이아웃과 포커스가 보존되는지도 확인한다.
- 설정을 다시 읽어 적용값을 확인한다. 창 크기와 배율의 재실행 후 유지 여부는 다음 정상 실행에서 확인한다.
- 기준 앱, 적용 전후 크기·배율, 화면 비교 결과와 남은 항목을 로컬 검증 기록에 남긴다. 대화 내용·계정 정보·원본 스크린샷은 공개 저장소에 넣지 않는다.

이 문서는 설치 AI의 수행 기준이다. `install_skills.py`나 `install_global_rules.py`가 앱 크기를 자동으로 읽거나 변경하는 기능은 아니다.
