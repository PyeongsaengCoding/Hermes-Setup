# 사용자 의도·정정 반영 전역 규칙 추가 · 2026-10-08

Hermes-Setup 배포 규칙과 현재 기본 프로필의 `$HERMES_HOME/SOUL.md`에 동일한 짧은 원칙 추가

- 사용자 목적과 에이전트가 선택한 방법 구별, 초기 해석은 잠정적으로 취급
- 정정·반대 근거 발생 시 해석·계획·위임 재검토와 잘못된 가정에 따른 작업 수정·중단
- 에이전트 제안을 사용자 확정 요구로 취급하지 않으며 세부 방법의 자율 판단 유지
- 완료 판정에서 시험 통과와 사용자 의도 충족을 함께 확인

배포 원본은 [templates/user-intent.md](../templates/user-intent.md). 설치기와 설치 안내에 반영하고 기존 규칙 보존·중복 방지·충돌 시 쓰기 중단 검사 추가. 이 단계에서는 기본 프로필에 새 규칙만 추가하고 기존 Aside·보고서·문체 규칙과 다른 프로필 보존. 이후 승인된 보고서 전역 섹션 삭제와 스킬 설치 기준 정리는 [후속 결과](2026-10-08-document-skills.md)에 기록

## 검증

- `python3 scripts/check.py`, `python3 -m unittest discover -s tests -v`, `git diff --check` 통과
- 전체 단위시험 55개 통과. 미리보기·반복 적용·기존 내용 보존·새 의도 규칙의 충돌 및 손상 검사 포함
- 현재 기본 프로필의 새 규칙이 배포 원본과 일치하고 관리 구간이 한 번만 존재함을 확인
